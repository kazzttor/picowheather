# RP2040 + ESP8285 (Pico Clone Barato) - Guia de Instalação

Guia completo para instalação do PicoWeather em clones de Raspberry Pi Pico com ESP8285 integrado.

## 🎯 **Visão Geral**

### **Configuração**

- **Placa**: RP2040 + ESP8285 (Pico Clone)
- **Display**: ST7567 LCD 128x64 (SPI)
- **Sensores**: AHT20, BMP280 (I2C)
- **WiFi**: ESP8285 via UART
- **FM Transmissor**: QN8027 (I2C)
- **Botões**: 4 botões táteis

### **Características**

- Display LCD de alta visibilidade
- WiFi ESP8285 integrado
- Transmissor FM completo
- Configuração mais robusta
- Ideal para aplicações completas

### **Conexões Essenciais**

#### **Display ST7567 (SPI)**

```text
Display ST7567     →    RP2040 + ESP8285
VCC (3.3V)         →    3V3 (Pin 36)
GND                →    GND (Pin 38)
SCK                →    GP14 (Pin 20)
MOSI/SDA           →    GP15 (Pin 22)
DC                 →    GP12 (Pin 16)
CS                 →    GP13 (Pin 18)
RST                →    GP11 (Pin 14)
```

#### **Sensores (I2C0)**

```text
AHT20/BMP280       →    RP2040 + ESP8285
VCC (3.3V)         →    3V3 (Pin 36)
GND                →    GND (Pin 38)
SDA                →    GP8 (Pin 36)
SCL                →    GP9 (Pin 38)
```

#### **FM Transmissor QN8027 (I2C1)**

```text
QN8027             →    RP2040 + ESP8285
VCC (3.3V)         →    3V3 (Pin 36)
GND                →    GND (Pin 38)
SDA                →    GP6 (Pin 10)
SCL                →    GP7 (Pin 8)
```

#### **ESP8285 WiFi (UART)**

```text
ESP8285            →    RP2040 + ESP8285
VCC (3.3V)         →    3V3 (integrado)
GND                →    GND (integrado)
TX                 →    GP0 (Pin 3) - UART0_RX
RX                 →    GP1 (Pin 5) - UART0_TX
EN                 →    GP22 (Pin 32) - Enable
```

#### **Botões**

```text
Botão              →    RP2040 + ESP8285
UP                 →    GP21 (Pin 30) + 3V3
DOWN               →    GP20 (Pin 28) + 3V3
SELECT             →    GP19 (Pin 26) + 3V3
BACK               →    GP18 (Pin 24) + 3V3
```

## ⚙️ **Configuração do Software**

### **1. Preparar o MicroPython e Firmware ESP8285**

#### **⚠️ AVISO IMPORTANTE - Firmware Dual**

Os clones de Pico com ESP8285 **NÃO** usam o firmware padrão do Pico W. Eles requerem:

- Firmware específico para RP2040 (com bridge UART)
- Firmware separado para ESP8285 (módulo WiFi)

#### **Passo 1: Flash do Firmware ESP8285**

##### **1.1. Instalar Firmware de Bridge no RP2040**

```bash
# Baixe Serial_port_transmission.uf2 do repositório:
# https://github.com/mocacinno/rp2040_with_esp8285

# Procedimento:
# 1. Pressione BOOTSEL (botão mais próximo do USB)
# 2. Conecte o Pico ao computador
# 3. Arraste Serial_port_transmission.uf2 para o drive RPI-RP2
# 4. Aguarde o reboot automático
```

##### **1.2. Flash do Firmware ESP8285**

```bash
# 1. Baixe ESP Flash Download Tool:
# https://www.espressif.com/en/support/download/other-tools

# 2. Prepare o ESP8285 para flash:
# - Desconecte o Pico
# - Pressione o botão mais distante do USB
# - Mantenha pressionado e conecte ao PC

# 3. Configure o Flash Tool:
# - Chip Type: ESP8285
# - Firmware: WIFI-ESP8285_upgrade.bin (do repositório)
# - Endereço: 0x0
# - SPI Speed: 40 MHz
# - SPI Mode: DOUT
# - COM Port: Verificar no Device Manager

# 4. Execute o flash e aguarde conclusão
```

#### **Passo 2: Instalar MicroPython no RP2040**

```bash
# Após flash do ESP8285:
# 1. Desconecte o Pico
# 2. Pressione BOOTSEL (botão próximo ao USB)
# 3. Conecte ao computador
# 4. Use firmware RP2040 genérico (não Pico W)
# 5. Visite: https://micropython.org/download/rp2-pico/
# 6. Arraste o arquivo .uf2 para o drive RPI-RP2
```

#### **Passo 3: Verificação da Instalação**

```python
# No console MicroPython, teste a comunicação ESP8285:
import machine
import time

# Configurar UART para ESP8285
uart = machine.UART(0, 115200)
uart.write('AT\r\n')
time.sleep(0.1)
response = uart.read()
print(f"ESP8285 response: {response}")

# Resposta esperada: b'AT\r\r\nOK\r\n'
# Se não responder, refaça o procedimento de flash
```

#### **Debugging do ESP8285**

**Usando Putty para AT Commands:**

```bash
# 1. Re-flash RP2040 com Serial_port_transmission.uf2
# 2. Abra Putty
# 3. Connection type: Serial
# 4. COM port: correto (verificar Device Manager)
# 5. Speed: 115200
# 6. Conecte

# Comandos AT (pressione Enter depois de cada comando):
AT          # Teste básico
AT+GMR      # Versão do firmware
AT+CWMODE=1 # Modo estação
AT+CWJAP?"  # Listar redes
```

**Se o ESP8285 não responder:**

1. Verifique se o firmware bridge foi instalado corretamente
2. Confirme se o firmware ESP8285 foi flashado
3. Teste com outro cabo USB
4. Verifique se os botões estão funcionando
5. Tente o procedimento completo novamente

#### **Problemas Comuns e Soluções**

| Problema | Causa Provável | Solução |
| --- | --- | --- |

## 🚀 **Procedimento de Instalação**

### **Passo 1: Montagem do Hardware**

1. **Montagem na Protoboard**
   - Use protoboard grande (800 pontos)
   - Deixe espaço para todos os componentes
   - Organize por seções (display, sensores, WiFi, FM)

2. **Conectar Display ST7567**
   - Conecte usando barramento SPI
   - Verifique todos os pinos (SCK, MOSI, DC, CS, RST)
   - Teste contraste ajustando no config.json

3. **Conectar Sensores**
   - Conecte AHT20 e BMP280 no I2C0
   - Use GP8/GP9 para evitar conflitos
   - Verifique alimentação 3.3V

4. **Conectar FM Transmissor**
   - Conecte QN8027 no I2C1
   - Use GP6/GP7 separados
   - Adicione antena FM (fio ~17cm)

5. **Conectar ESP8285**
   - Verifique conexões UART
   - Conecte pino enable (GP22)
   - Teste comunicação serial

6. **Conectar Botões**
   - Conecte 4 botões com pull-ups
   - Use GPIOs específicos
   - Teste cada botão individualmente

### **Passo 2: Instalação do Software**

1. **Instalar MicroPython**
   - Use arquivo RP2040 genérico
   - Verifique boot normal

2. **Upload do Projeto**
   - Copie todos os arquivos
   - Mantenha estrutura de diretórios

3. **Configuração Completa**
   - Copie config_pico_clone.json para config.json
   - Edite configurações WiFi
   - Ajuste frequência FM se necessário

### **Passo 3: Teste e Validação**

1. **Teste Básico**

   ```python
   # No console MicroPython:
   import main
   ```

2. **Verificar Hardware Completo**


## 🚨 **Troubleshooting Específico para Clones ESP8285**

### **Problema: WiFi Não Funciona**

**Sintomas:**

- `wifi.status` retorna "Disconnected"
- Erro "Failed to start CYW43"
- Nenhuma rede WiFi detectada

**Solução Passo a Passo:**

1. **Verifique se é clone genuíno:**

   ```python
   # No console MicroPython:
   import machine
   print(machine.unique_id())
   # Clones geralmente têm IDs diferentes
   ```

2. **Reflashe firmware ESP8285:**
   - Siga o procedimento "Passo 1" acima
   - Use firmware WIFI-ESP8285_upgrade.bin
   - Verifique se flash foi bem-sucedido

3. **Teste comunicação UART:**

   ```python
   import machine
   uart = machine.UART(0, 115200)
   uart.write('AT\r\n')
   print(uart.read())  # Deve retornar "OK"
   ```

### **Problema: ESP8285 Não Responde**

**Sintomas:**

- UART não retorna nada
- Putty não conecta
- AT commands falham

**Solução:**

1. **Verifique firmware bridge:**
   - Reinstale Serial_port_transmission.uf2
   - Confirme boot correto

2. **Teste hardware:**
   - Verifique se botão de reset do ESP8285 funciona
   - Teste com outro cabo USB
   - Verifique alimentação 3.3V

3. **Use modo de debug:**

   ```python
   # No modo bridge (Serial_port_transmission.uf2)
   # Use Puty para enviar AT commands diretamente
   ```

### **Problema: Instalação Incorreta**

**Sintomas:**

- Usou firmware Pico W por engano
- Sistema não inicializa
- Erros de importação

**Solução:**

1. **Identifique firmware incorreto:**
   - Se usou firmware Pico W, o ESP8285 não funcionará
   - Precisa usar firmware RP2040 genérico

2. **Reinstale do zero:**
   - Flash ESP8285 primeiro
   - Depois flash RP2040 com MicroPython
   - Finalmente faça upload do PicoWeather

### **Problema: Confusão com Pico W Genuíno**

**Como Identificar:**

- **Pico W Genuíno**: Tem chip CYW43 visível na placa
- **Clone ESP8285**: Tem chip adicional pequeno (ESP8285)
- **Vendedor**: TZT e similares vendem clones

**Se comprou clone pensando ser Pico W:**

1. **Não se preocupe** - O clone é funcional!
2. **Siga este guia** - Procedimento correto para clones
3. **Benefícios** - Clone ESP8285 pode ser mais estável

### **Problema: Flash Falha**

**Sintomas:**

- ESP Flash Tool reporta erro
- Dispositivo não detectado
- COM port inválido

**Solução:**

1. **Verifique driver USB:**
   - Instale drivers CP210x ou CH340
   - Use Device Manager para identificar

2. **Pressione botão correto:**
   - Para flash ESP8285: botão mais distante do USB
   - Para flash RP2040: botão BOOTSEL (mais próximo)

3. **Tente velocidades diferentes:**
   - Reduza SPI speed para 20 MHz
   - Use COM port diferente se disponível

### **Problema: Performance WiFi**

**Sintomas:**

- Conexão lenta
- Desconexões frequentes
- Baixo alcance

**Solução:**

1. **Verifique antena:**
   - Use fio de 17cm como antena
   - Posicione longe de metal

2. **Configure otimizações:**

   ```python
   # No config.json:
   "wifi": {
     "type": "esp8285",
     "uart_bus": 0,
     "baudrate": 115200,
     "timeout": 10000
   }
   ```

3. **Teste diferentes canais:**
   - Mude canal do roteador (1, 6, 11)
   - Evite canais congestionados
